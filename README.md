# OpsAgent - 智能运维 Agent

OpsAgent：基于大语言模型的跨主机智能运维 Agent
 
基于大语言模型（GLM-4）与 ReAct 循环架构的智能运维系统。支持通过网页聊天交互，自主调用 Linux 命令进行远程故障排查，并提供完善的安全拦截与审计功能。
 
核心功能
 
双模式智能诊断：支持“命令+报错”的静态分析（直接给修复代码）与“现象描述”的动态排查（自主执行命令排查）。
跨主机远程执行：基于 SSH 协议，在 Windows 主机上直接操作 Linux 虚拟机。
安全网关（Human-in-the-loop）：白名单命令直接执行，白名单外命令需在网页端手动点击【同意】/【拒绝】授权；毁灭性命令（如  rm -rf / ）底层强制拦截。
多轮对话记忆：支持上下文连贯对话，自动维护最近 N 轮历史（滑动窗口机制）。
SOP 知识库检索（RAG）：接入本地 JSON 知识库，提升特定故障场景下的诊断准确率。
MySQL 操作审计：记录每一次用户提问、AI 决策、执行的命令、结果与耗时，实现操作可追溯。
 
系统架构（数据流转）
 
1. 用户交互：用户在浏览器网页中输入指令（如“帮我看看磁盘空间”）。
2. Web 接收：Flask 后端接收到请求，将指令和历史记忆打包发给大模型。
3. AI 思考：大模型判断需要执行  df -h ，返回工具调用请求。
4. 安全审查：后端检查命令是否在白名单内。安全则直接放行，危险或未知命令则暂停，等待用户在网页上点击“同意”。
5. 远程执行：审查通过后，通过 Paramiko（SSH）将命令发到 Ubuntu 虚拟机执行。
6. 结果回传：虚拟机执行完，把结果原路返回给后端，再发给大模型。
7. 最终回复与审计：大模型根据结果生成最终回答展示给用户，同时把这一步操作记录到 MySQL 数据库中。
 
技术栈
 
大模型：智谱 GLM-4-Flash（Function Calling / ReAct）
后端：Python / Flask
前端：HTML / CSS / JavaScript
远程通信：Paramiko（SSH）
数据库：MySQL
虚拟机环境：VMware + Ubuntu 22.04
